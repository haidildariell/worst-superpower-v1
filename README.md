Entry for the [Worst Superpower bounty](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe) on make.fun: invent the most useless superpower in one line of at most 140 characters.

Running `main.py` writes the entry line to `/output/entry.txt` (or the path in `OUTPUT_PATH`).

The entry: "I can summon rain indoors, but only in a column directly over my own head, and only when I'm already soaked."
